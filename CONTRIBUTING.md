# Contributing

Small, focused improvements are welcome.

- Keep the instructions useful across different AI tools.
- Keep technical terms, code, values, conditions, and important risks intact.
- Do not add text from the official ASD-STE100 standard or vocabulary.
- Do not claim that this project certifies ASD-STE100 compliance.
- Include a short example when a change affects how a skill writes.

Open an issue first for a large change. For a small change, open a pull request with a brief reason and an example of the result.
